# ISSUE-019 Prototype Studio UI

## Goal

Create visual approval interface for commercial prototypes.

## Scope

- show company logo candidates;
- show selected templates;
- show generated mockups;
- show QC score and warnings;
- approve/reject/rerender actions;
- switch template action.

## Acceptance criteria

- User can approve logo.
- User can approve/reject mockups.
- Rejected mockups do not appear in offer.
- Approved mockups are linked to offer assets.
