# ISSUE-014 Runtime mockup pack manager

## Goal

Create certified runtime templates from exported PSD layers.

## Scope

- upload base.png;
- upload mask.png optional;
- upload shadow.png optional;
- upload highlight.png optional;
- upload preview.jpg;
- configure placement;
- configure safe_area;
- tags and quality_score.

## Acceptance criteria

- Template can be rendered without PSD.
- UI previews placement and safe area.
- Template status/active flag exists.
- Template has product_type and technology.
