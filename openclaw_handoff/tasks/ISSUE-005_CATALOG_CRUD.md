# ISSUE-005 Product catalog CRUD

## Goal

Create product package and product item management.

## Scope

- product package list;
- create/edit/deactivate package;
- product items inside package;
- technology;
- min quantity;
- price_from;
- production_days;
- target_industries;
- margin fields if applicable.

## Acceptance criteria

- Producer/admin can manage packages.
- Agent can view active packages.
- Disabled packages are not used in offer generation.
