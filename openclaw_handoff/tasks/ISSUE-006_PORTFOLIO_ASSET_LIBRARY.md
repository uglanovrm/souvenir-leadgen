# ISSUE-006 Portfolio asset library

## Goal

Allow producer to upload and tag real work photos.

## Scope

- upload images to portfolio-assets bucket;
- create portfolio_assets rows;
- tags: technology, industry, product_type, material, quality_score;
- allowed_for_offer flag;
- gallery UI.

## Acceptance criteria

- Uploaded image appears in gallery.
- Metadata can be edited.
- Offer generator can query allowed assets.
