# Project Context for OpenClaw Sessions

We are building a production MVP called Souvenir Lead-Gen Offer System.

The user resources are limited:

- MacBook Air M1 13;
- OpenClaw + Codex;
- Supabase;
- LM Studio + Gemma 12B;
- no expensive infra.

The implementation must be lean, Supabase-first, TypeScript-first.

The riskiest product area is Prototype Studio: commercial-quality mockups with client logo. Avoid cheap sticker-like renders.

Implementation should always optimize for:

- reliable MVP;
- low infrastructure cost;
- human approval;
- small PRs;
- no unsafe autonomous sending;
- no overengineering.
