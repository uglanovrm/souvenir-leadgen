# ISSUE-016 Template selector

## Goal

Select best mockup templates for a lead/offer brief.

## Scope

- product_type match;
- technology match;
- industry_tags match;
- logo aspect ratio fit;
- template quality score;
- return top 3–5 templates with explanation.

## Acceptance criteria

- Selector returns ranked templates.
- Poor aspect ratio templates are penalized.
- Inactive templates are excluded.
- Explanation is visible in Prototype Studio.
