# ISSUE-020 Offer export, message prepare, deals and commissions

## Goal

Complete the commercial handoff after offer/prototypes approval.

## Scope

- HTML offer preview;
- PDF export job;
- prepared message creation;
- legal/manual send gate;
- deal creation from offer;
- commission calculation.

## Acceptance criteria

- Approved offer can be exported as HTML/PDF.
- Prepared message includes subject/body/attachment link.
- Automatic send is blocked without explicit legal basis.
- Deal can be created from offer.
- Commission is calculated and visible.
